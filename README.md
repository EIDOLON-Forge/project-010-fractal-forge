## ✨ Features

Instead of calculating every pixel on the CPU, Fractal Forge uses an OpenGL fragment shader to perform calculations directly on the GPU. This allows for real-time zooming, navigation, and high iteration counts across thousands of screen fragments in parallel.

*   **Dual Fractal Modes:** Instantly toggle between the Mandelbrot Set and Julia Sets.
*   **GPU Acceleration:** Full GLSL fragment shader rendering for real-time 60FPS exploration.
*   **Smooth Escape-Time Coloring:** Continuous escape value estimation produces smooth gradients instead of harsh iteration bands, revealing deeper mathematical details.
*   **Dynamic Palettes:** Includes custom color mappings (EIDOLON, FIRE, OCEAN, VIOLET, MATRIX) with real-time animated palette shifting.
*   **Interactive Exploration:** Deep zoom capabilities, iteration control, and random Julia constant generation.
*   **Sleek UI:** Dark, EIDOLON-style interface with audio toggles and screenshot saving.

## 🚀 Getting Started

### Prerequisites
*   **OS:** Windows (Linux/macOS compatible with correct OpenGL drivers)
*   **Python:** 3.12+
*   **Hardware:** An OpenGL 3.3-compatible GPU (NVIDIA RTX 3060 or similar recommended, but no CUDA required).

### Installation

1. **Clone the repository:**
   ```bash
   git clone https://github.com/EIDOLON-Forge/project-010-fractal-forge.git
   cd project-010-fractal-forge
   ```

2. **Create and activate a virtual environment:**
   ```bash
   # Windows Command Prompt / PowerShell
   python -m venv .venv
   .venv\Scripts\activate
   
   # Git Bash
   source .venv/Scripts/activate
   ```

3. **Install dependencies:**
   ```bash
   python -m pip install -r requirements.txt
   ```
   *(This installs `pygame`, `PyOpenGL`, `PyOpenGL_accelerate`, and `numpy`)*

### Running the Application

To start the fractal explorer:
```bash
python main.py
```

**Smoke Test:**
Fractal Forge includes a lightweight startup test to verify your OpenGL rendering pipeline initializes correctly without loading the full app:
```bash
python main.py --smoke-test
```

## 🧠 Under the Hood: Math & Architecture

### The Mathematics
Both fractals are generated by repeatedly applying the formula: `z = z² + c`

*   **Mandelbrot Mode:** The system starts with `z = 0` and sets `c` to the pixel's coordinate on the complex plane. If the magnitude of `z` exceeds 2 after repeated iterations, the point escapes.
*   **Julia Mode:** The value of `c` remains a fixed complex constant, and `z` begins as the pixel's coordinate. Changing `c` (using the `J` key) produces dramatically different, infinitely complex structures.

### Why GPU Rendering?
A standard CPU renderer calculates `z² + c` for hundreds of iterations per pixel. At a 1200×800 resolution, that's nearly a million pixels calculated sequentially—which is painfully slow in Python.

By routing the application through Pygame to OpenGL, we pass the mathematical heavy lifting to a **GLSL Fragment Shader**. The GPU processes those 960,000 screen fragments in parallel across thousands of CUDA/Stream cores, demonstrating a core EIDOLON principle: *Sometimes the biggest performance improvement comes from moving the algorithm to the hardware designed to execute it.*

## 🛠️ Troubleshooting

*   **OpenGL Context Error:** Ensure your GPU supports OpenGL 3.3+ and your graphics drivers are up to date. You can test your Pygame OpenGL context directly:
    ```bash
    python -c "import pygame; pygame.init(); pygame.display.gl_set_attribute(pygame.GL_CONTEXT_MAJOR_VERSION,3); pygame.display.gl_set_attribute(pygame.GL_CONTEXT_MINOR_VERSION,3); pygame.display.set_mode((640,480), pygame.OPENGL); print('OpenGL context created'); pygame.quit()"
    ```
*   **Slow Performance:** Decrease iterations (`-`), close background GPU-intensive apps, or ensure your system is utilizing its dedicated GPU rather than integrated graphics.
*   **Dependency Issues:** Try forcing an upgrade of the core libraries: 
    ```bash
    python -m pip install --upgrade PyOpenGL PyOpenGL_accelerate pygame numpy
    ```
