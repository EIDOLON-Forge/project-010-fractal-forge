# EIDOLON #010 — Fractal Forge

An interactive GPU-accelerated Mandelbrot and Julia fractal explorer built with Python, Pygame, OpenGL, and GLSL.

Part of the **EIDOLON 500+ Project Journey** — a long-term experiment in seeing how far one person can take coding by building something new every day.

---

## What Is This?

Fractal Forge is an interactive mathematical visualization that renders two famous fractal systems:

- Mandelbrot Set
- Julia Sets

Instead of calculating every pixel on the CPU, the project uses an OpenGL fragment shader to perform the fractal calculations directly on the GPU.

The result is an interactive fractal explorer capable of real-time zooming, navigation, palette changes, and high iteration counts.

---

## The Idea

The Mandelbrot set is generated by repeatedly applying:

```text
zₙ₊₁ = zₙ² + c


For the Mandelbrot set:

```
z₀ = 0
c = pixel position
```

For a Julia set:

```
z₀ = pixel position
c = fixed complex constant
```

For each pixel, the shader repeatedly applies the equation and determines whether the value escapes.

That simple rule creates incredibly complex structures.

### GPU Rendering

Fractal calculations are performed inside a GLSL fragment shader rather than through Python pixel-by-pixel calculations.

The rendering pipeline is approximately:

```
Python
   │
   ▼
Pygame
   │
   ▼
OpenGL
   │
   ▼
GLSL Fragment Shader
   │
   ▼
GPU
   │
   ▼
Fractal Image
```

This allows the GPU to process thousands of screen fragments in parallel.

# Mandelbrot Mode

In Mandelbrot mode, each screen coordinate represents a complex number `c`.

The shader begins with:

```
z = 0
```

and repeatedly calculates:

```
z = z² + c
```

If:

```
|z| > 2
```

the point is considered outside the Mandelbrot set.

The number of iterations before escape determines the pixel's color.

---

# Julia Mode

Julia mode uses the same mathematical system:

```
zₙ₊₁ = zₙ² + c
```

but instead of changing `c` for every pixel, the value of `c` remains fixed.

Changing the Julia constant produces dramatically different fractal structures.

This makes Julia sets especially interesting to explore interactively.

---

# Smooth Coloring

A basic fractal renderer can simply color a pixel according to the number of iterations required for escape.

Fractal Forge goes further by using smooth escape-time coloring.

Instead of producing harsh iteration bands, the renderer estimates a continuous escape value.

This produces smoother gradients and reveals significantly more detail.

---

# Why GPU Rendering?

The original CPU renderer calculated the fractal approximately like this:

```
for every pixel:
    for every iteration:
        calculate z² + c
```

At a resolution of:

```
1200 × 800
```

that means:

```
960,000 pixels
```

with potentially hundreds of iterations per pixel.

Doing that entirely in Python is expensive.

The GPU version instead sends the mathematical problem to a GLSL fragment shader.

Conceptually:

```
960,000 screen fragments
        │
        ▼
     GPU cores
        │
        ▼
 parallel fractal calculations
```

This makes GPU acceleration a natural next step in the EIDOLON progression.

# Performance

Performance depends on:

- GPU
- Display resolution
- Iteration count
- Zoom level
- OpenGL driver
- Background GPU workload

The GPU renderer is designed to avoid Python performing the expensive per-pixel fractal calculations.

For best performance:

- Use an up-to-date GPU driver.
- Close unnecessary GPU-intensive applications.
- Avoid extremely high iteration counts unless necessary.
- Use a dedicated GPU where available.

# Troubleshooting

## OpenGL Context Error

If the program reports an OpenGL context error, verify that your GPU supports OpenGL 3.3 or newer and that your graphics driver is installed correctly.

You can test the basic Pygame OpenGL context with:

```
python -c "import pygame; pygame.init(); pygame.display.gl_set_attribute(pygame.GL_CONTEXT_MAJOR_VERSION,3); pygame.display.gl_set_attribute(pygame.GL_CONTEXT_MINOR_VERSION,3); pygame.display.set_mode((640,480), pygame.OPENGL); print('OpenGL context created'); pygame.quit()"
```
